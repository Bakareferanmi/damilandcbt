Academic session

Every session has its own students and exams, and student numbers start again at 001. Only students of the current session can log in. Old sessions stay saved and can be viewed (read-only) from the Session menu in the sidebar.

Start a new session

The current session’s students will no longer be able to log in, so do this only when the new school year begins. Nothing is deleted.

Exams in this session

A session can hold several exams (for example First Term, Mock, Second Term). Each exam has its own questions, results and exam length. Students are shared. Only the live exam can be sat: starting a new exam makes it live, and anyone still writing the previous one is submitted and marked.
